# THE WORLD — 21 November 2026

A one-page newspaper front page summing up Saturday, 21 November 2026: Russia's huge overnight barrage on Ukraine that also landed in Poland, the fallout from the Trump-Xi-Putin summit, the world court's genocide ruling on Myanmar, the UK-EU deal to rebuild ties, and COP31 talks running over.

`main.py` is pure Python 3 standard library. It draws the page with its own 5x7 bitmap font and a minimal PNG encoder, so the output is byte-identical on every run.

## Run

MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
